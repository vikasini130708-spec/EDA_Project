# Exploratory Data Analysis (EDA) of Titanic Dataset

## Introduction

Exploratory Data Analysis helps identify patterns, trends, and relationships in data. This project analyzes the Titanic passenger dataset using Python.

## Objective

To explore passenger information and identify factors associated with survival using statistical summaries and visualizations.

## Dataset

The Titanic dataset contains 891 passenger records and 15 columns.

## Tools Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Seaborn

## Methodology

1. Loaded and inspected the dataset.
2. Generated descriptive statistics.
3. Examined missing values.
4. Created survival count, survival-by-gender, age distribution, and fare distribution graphs.
5. Generated a correlation heatmap.
6. Compared survival rates by gender, passenger class, and embarkation town.

## Key Findings

* Survival rates differed between male and female passengers.
* Passenger class was associated with survival outcomes.
* Passenger ages and fares showed considerable variation.
* Some columns contained missing values.

## Conclusion

The analysis demonstrates how statistical summaries and visualizations can be used to understand a dataset and discover relationships between passenger characteristics and survival outcomes.
